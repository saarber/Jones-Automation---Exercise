# Jones automation exercise

This small project uses JavaScript and Playwright Test to complete and submit the call-back form at <https://test.netlify.app/>.

## Setup in Windows PowerShell

From this project folder, run:

```powershell
npm.cmd install
npx.cmd playwright install chromium
```

`npm.cmd install` installs the JavaScript dependency. The second command installs the Chromium browser that Playwright controls.

## Run the test

```powershell
npm.cmd test
```

To watch Chromium while the test runs:

```powershell
npm.cmd run test:headed
```

To open the HTML report after a run:

```powershell
npm.cmd run report
```

The pre-submit and post-submit screenshots are saved inside `test-results/` for the individual test run and are also attached to the HTML report in `playwright-report/`. These generated folders are intentionally ignored by Git.

## What the test does

`tests/request-callback.spec.js` opens the site, fills five contact fields with fictional data, selects `51-500` employees, verifies the completed values, and takes a full-page screenshot. It then submits the form, verifies the real thank-you URL and visible confirmation, and takes another full-page screenshot before logging success.

`playwright.config.js` keeps the runner setup small: it uses only Chromium, disables retries, prints a concise list report in the terminal, and creates Playwright's built-in HTML report.

`package.json` contains the Playwright dependency and the three commands shown above. `package-lock.json` is generated by npm so future installs use the same dependency versions.

## Beginner notes

- A **locator** tells Playwright how to find something. `getByLabel('Email')` finds the input through its visible label, while `getByRole('button', ...)` finds the button the way assistive technology does.
- `async` functions can pause for browser work. `await` makes each action finish before the next one starts.
- An `expect` assertion checks that the page is in the required state. Playwright automatically retries these checks for a short time, which is more reliable than fixed sleeps.
- The built-in `page` fixture is a fresh browser page supplied by Playwright for the test. The runner creates and closes it automatically.
- The first screenshot records the verified, completed form before submission. The second records the thank-you page after successful submission is verified.
